# Git Commands to Commit Your Bedrock App

## First Time Setup (run once)
git init
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git

## Add and Commit All Files
git add .
git commit -m "Initial commit: AWS Bedrock multimodal content viewer

- React.js frontend with query interface and content viewer
- Node.js backend with AWS Bedrock Agent integration
- Multimodal content parsing and visualization
- Complete project setup with dependencies and configuration"

## Push to GitHub
git branch -M main
git push -u origin main

## Alternative: If repository already exists
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git add .
git commit -m "Add AWS Bedrock multimodal content viewer"
git push origin main

---
REMEMBER TO:
1. Replace YOUR_USERNAME and YOUR_REPO_NAME with your actual GitHub details
2. Create the repository on GitHub.com first if it doesn't exist
3. Make sure git is installed on your system
